# Ai-financial-intelligence-system

Built a multi-company web platform with double-entry accounting, live Chart.js dashboards, and auto-generated income statements, balance sheets, and cash-flow statements, plus bilingual PDF/Excel reports.
Implemented machine-learning revenue and cash-flow forecasting (Holt-Winters), Isolation Forest anomaly detection, and indicator-based risk scoring, with Saudi VAT and invoices carrying ZATCA e-invoicing fields and QR codes.
Delivered a full English/Arabic (RTL) interface and a bilingual AI chatbot
